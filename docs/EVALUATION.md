# RAGAS-light 在线评估

## 为什么是 light

标准在线判分如果为四个指标各发起一次 LLM 调用，会明显增加成本和质量结果到达时间。
本项目用一次异步 Judge 调用返回四项分数，失败时切换为可解释词法回退；回答发送不等待
完整评估。发送前的忠实度门禁是独立链路，不能被异步评估替代。

## 四项指标

1. **忠实度（faithfulness）**：答案中可由检索上下文支持的事实声明数 / 全部事实声明数。
2. **相关性（answer relevancy）**：答案是否直接回应用户问题。
3. **精确率（context precision）**：检索块是否相关、噪声是否少，且相关内容是否靠前。
4. **召回率（context recall）**：参考答案事实被检索上下文覆盖的比例。

忠实度定义与 RAGAS 的声明支持比例一致。上下文召回率必须有参考答案才能成为标准指标：

- `gold_reference`：调用方提供了人工参考答案。
- `online_proxy`：在线无参考答案时，用问题信息需求做代理；前端和日志必须保留该标记。

## 忠实度门禁

默认目标由 `HALLUCINATION_TARGET=0.90` 设置：

1. 生成草稿。
2. 拆分事实声明并检查证据支持。
3. 未达标时把无证据声明反馈给生成节点重写。
4. 达到最大重试次数仍失败，则只返回知识库原文摘录。
5. 最终答案通过后才发送给用户。

## 数据闭环

- `outputs/evaluations.jsonl`：问题、路由关联后的每轮四维分数。
- `outputs/feedback.jsonl`：用户反馈、可选评论和纠正答案。
- 两个文件通过 `session_id + turn_id` 关联。

建议离线每周汇总：忠实度低于目标的轮次、低精确率来源、低召回率主题、用户差评及
纠正答案。优先补知识和修检索，再调整提示词；不要用提高 Judge 分数替代实际质量改进。
