# 生产化路线图

## 本轮已完成

- React 多轮对话平台与图片上传。
- FastAPI SSE 流式接口。
- LangGraph 检测、并行检索、三级路由、生成、门禁、重试状态图。
- BGE + Chroma 主检索与缺依赖时的关键词降级检索。
- 滑动窗口会话管理。
- RAGAS-light 四维异步评估、后端实时日志和 JSONL 留存。
- 每轮用户反馈闭环。
- 受控响应时间前后基准与浏览器桌面/移动验收。

## 下一阶段建议

1. **金标准问答集**：每个病虫害至少 30~50 个经植保专家审校的问题、参考答案和
   参考文本块；用它替代在线代理召回率做离线回归。
2. **真实延迟基准**：目标硬件上记录冷/热启动、P50/P95、首字节、完整答案、评估到达、
   YOLO 和 BGE 分项耗时。
3. **持久化会话**：用 PostgreSQL/Redis 保存会话、模型版本和 checkpointer，支持多进程。
4. **知识库审校**：补充来源 URL、发布日期、地区适用范围和专家审核状态。
5. **引用级追踪**：把回答声明与 `chunk_id` 做显式映射，而不只展示来源列表。
6. **安全与运维**：鉴权、限流、日志脱敏、上传病毒扫描、CSP、数据保留策略和监控告警。
7. **检测模型评估**：建立独立图片测试集，评估每类 Precision、Recall、mAP、漏检和误检。
8. **许可证复核**：商业或闭源使用前核实模型权重、知识文档和依赖许可证。
